# Práctica — Los 4 pilares de la POO + getters y setters

Alumno: Fabricio Augusto

| Archivo | Tema | Qué se modela |
|---|---|---|
| `ej1.ts` | Abstracción | `Producto` para un sistema de ventas |
| `ej2.ts` | Encapsulamiento | `CuentaBancaria` con saldo e historial privados |
| `ej3.ts` | Herencia | `Empleado` y `EmpleadoFijo` |
| `ej4.ts` | Polimorfismo | `EmpleadoPorHoras`, `EmpleadoPorComision` y `calcularNomina()` |
| `ej5.ts` | Getters y setters | `Persona` con validación de edad y email |

## Cómo ejecutarlo

Necesita Node 22.18 o superior (ejecuta los `.ts` directamente).

```bash
npm install
npm run ej1   # y así con ej2, ej3, ej4, ej5
npm run typecheck   # revisa los tipos con TypeScript
```
